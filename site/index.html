01 / The proposition

Unix capabilities,
for what comes next.

The Cix Project develops Cix, a source-built Linux operating system for container infrastructure, and CBS, its build system. We are carrying Unix’s directness and composability into cloud-native, containerised and AI-shaped computing — so people can make computing work for them, instead of spending their time working around opaque layers.

03 / What an owner protects

Stewardship is a
technical responsibility.

01

Keep the contract visible.

Document the resource model, API boundaries, version identity and compatibility honestly. No hidden source of truth.

02

Make releases verifiable.

Publish keys independently, keep old keys for old artefacts, and make a release reproducible from the source trail.

03

Prefer durable interfaces.

Use ADRs and tests for hard-to-reverse decisions. Let implementation move without making operators guess.

04

Grow the contributor path.

Give builders a clear first issue, a working local loop, and a reason to trust that their work can land.

04 / Stewardship
